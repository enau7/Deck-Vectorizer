CardPond is a Magic: The Gathering deck analysis website that uses machine learning to graph and cluster cards by their text boxes.

Cards on the graph make clusters with mechanically similar cards, which can help you visually see themes in a deck.

If you have more questions about how CardPond works, feel free to get in touch!
